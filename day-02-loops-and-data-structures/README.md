# What I Learned

- I learned how to use `for` and `while` loops to repeat tasks and control program execution.
- I learned how to use `break` and `continue` to control loops based on specific conditions.
- I learned how to work with lists, sets, and dictionaries to store and organize data.
- I learned how to use list and dictionary comprehensions to create collections in a concise way.
- I also learned how to work with nested dictionaries and perform basic data analysis such as filtering, sorting, finding totals, and calculating averages.
